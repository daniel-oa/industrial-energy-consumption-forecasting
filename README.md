# Industrial Energy Consumption Analysis and Forecasting

## Overview

This project analyzes industrial energy consumption data and develops a machine learning model to forecast energy usage 15 minutes ahead.

The project uses the DAEWOO Steel Industry dataset, which contains energy and operating measurements recorded at 15-minute intervals throughout 2018. The analysis focuses on identifying temporal patterns in energy consumption and evaluating whether historical consumption and time-based features can improve short-term forecasting.

## Objective

The main objective is to predict energy consumption for the next 15-minute interval using historical consumption and temporal features.

The project follows a complete forecasting workflow:

- Data understanding
- Exploratory data analysis
- Data preprocessing and feature engineering
- Baseline and machine learning modelling
- Hyperparameter tuning
- Model evaluation and error analysis
- Model interpretation

## Dataset

The dataset was collected from DAEWOO Steel Co. Ltd. in South Korea and contains 35,040 observations recorded at 15-minute intervals throughout 2018.

The dataset is available through the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption).

The original dataset is not included in this repository. Download it from the UCI Machine Learning Repository and place the dataset in the `data/` directory as:

`Steel_industry_data.csv`

The project uses `Usage_kWh` as the target variable.

## Methodology

### Exploratory Analysis

The dataset was examined to understand:

- Energy consumption distributions
- Daily, weekly, and monthly patterns
- Time-of-day variation
- Weekday and weekend differences
- Relationships between energy consumption and other variables
- Short-term, daily, and weekly lag correlations

### Feature Engineering

The forecasting model uses:

- Hour
- Minute
- Month
- Day of week
- Weekday/weekend status
- Previous 15-minute consumption (`lag_1`)
- Previous 30-minute consumption (`lag_2`)
- Previous 1-hour consumption (`lag_4`)
- Previous 1-day consumption (`lag_96`)
- Previous 1-week consumption (`lag_672`)

The data was split chronologically into training, validation, and test sets to preserve the time-series structure.

### Models

The following approaches were evaluated:

1. Naive persistence baseline
2. Linear Regression
3. Random Forest
4. Tuned Random Forest

Random Forest hyperparameters were optimized using time-series cross-validation.

## Results

The final tuned Random Forest was evaluated on the previously unseen test set.

| Model | MAE (kWh) | RMSE (kWh) |
|---|---:|---:|
| Naive Baseline | 5.04 | 11.68 |
| Tuned Random Forest | **4.42** | **9.39** |

Compared with the persistence baseline, the tuned Random Forest achieved:

- **12.2% improvement in MAE**
- **19.5% improvement in RMSE**

## Key Findings

- Energy consumption shows strong short-term temporal dependence.
- The previous 15-minute consumption value is the most important predictor in the final Random Forest model.
- Historical consumption at daily and weekly intervals provides additional predictive information.
- Prediction errors are relatively low during low-usage periods and increase substantially during higher-consumption periods.
- The model has greater difficulty capturing rapid increases in energy demand, particularly around periods of increased industrial activity.

## Limitations

The dataset represents a single industrial facility and covers one year of observations, so the results may not generalize directly to other facilities or operating conditions.

The model also relies heavily on recent energy consumption and therefore has limited ability to anticipate sudden changes in demand. External operational information such as production schedules, holidays, maintenance activities, and other plant-specific events was not available in the dataset.

The model is therefore presented as a demonstration of short-term energy forecasting using the available historical data rather than as a deployment-ready forecasting system.

## Reproducing the Analysis

1. Clone the repository.
2. Install the required Python packages from `requirements.txt`.
3. Download the dataset from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption).
4. Place `Steel_industry_data.csv` in the `data/` directory.
5. Run the notebooks sequentially from `01` to `05`.

### Notebook Workflow

| Notebook | Purpose |
|---|---|
| `01_data_understanding.ipynb` | Dataset structure, variables, and time dimension |
| `02_exploratory_data_analysis.ipynb` | Energy consumption patterns and relationships |
| `03_data_preprocessing.ipynb` | Data preparation, feature engineering, and chronological splitting |
| `04_modelling.ipynb` | Baseline models, Random Forest, tuning, and final model selection |
| `05_model_evaluation_and_error_analysis.ipynb` | Test-set evaluation, error analysis, and model interpretation |

Notebook 03 generates the processed training, validation, and test datasets.

Notebook 04 trains and tunes the forecasting models and saves the final Random Forest model to the `models/` directory.

Notebook 05 loads the saved model and performs the final evaluation and error analysis.
